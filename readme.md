# 🌼 Jardín de Amor - Flores Amarillas 💛

Una página web romántica y interactiva dedicada a esa persona especial en tu vida.

## ✨ Características

- **Diseño romántico** con temática de flores amarillas
- **Animaciones interactivas** de flores y corazones
- **Efectos visuales** al hacer clic en los elementos
- **Totalmente responsive** (se adapta a móviles y tablets)
- **Contador de visitas** personalizado

## 🚀 Cómo usar

### Opción 1: Live Server (Recomendado)
1. Abre el proyecto en Visual Studio Code
2. Instala la extensión "Live Server"
3. Haz clic derecho en `index.html`
4. Selecciona "Open with Live Server"

### Opción 2: Navegador directo
1. Abre `index.html` directamente en tu navegador
2. ¡Disfruta de la experiencia!

## 🎨 Personalización

Para personalizar la página con tus nombres:

1. Abre `index.html`
2. Busca y reemplaza:
   - `rayo de sol` → Nombre de tu amor
   - `GHOST` → Tu nombre
3. Guarda los cambios
